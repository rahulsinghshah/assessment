# Trucking Load Rate Prediction Project

## Project Description
This project aims to predict the `posted_rate` for trucking loads based on various features such as pickup/delivery locations, distance, equipment type, weight, market index, and date-related attributes. The goal is to build a robust machine learning model that can accurately estimate load rates, assisting in logistics and pricing strategies.

## Problem Statement
Predicting transportation costs (posted rates) accurately is crucial for logistics companies to optimize pricing, manage bids, and ensure profitability. This project addresses the challenge of forecasting these rates using historical data and machine learning techniques.

## Data

Four main datasets are utilized in this project:
-   `train-test.csv`: Contains historical data used for model training and initial validation.
-   `validation.csv`: A new dataset for which `posted_rate` predictions are required.
-   `validation-predictions-template.csv`: A template file to structure the submission of predictions for `validation.csv`.
-   `december_chart_inputs.csv`: A specific dataset requiring `posted_rate` predictions for December, to be integrated into a chart.

## Preprocessing Steps

The `preprocess_data` function was developed and applied consistently to both training and validation/December datasets. The key preprocessing steps include:
1.  **Date Feature Extraction**: From the `date` column, new numerical features like `Year`, `Month`, `Day`, `DayOfWeek`, and `DayOfYear` are extracted.
2.  **Original Date Column Removal**: The original `date` column is dropped after feature extraction.
3.  **Handling Missing Numeric Values**: Missing values in numerical columns (e.g., `weight`, `market_index`) are imputed with the median of their respective columns. A binary `_is_missing` flag is added for each imputed column to indicate where values were originally missing.
4.  **Categorical to Numerical Conversion**: Object/string type columns (e.g., `pickup`, `delivery`, `equipment`) are converted into numerical codes using pandas `Categorical` type. A `+1` offset is applied to handle potential `NaN` values, though in this dataset, categorical columns had no missing values.

## Modeling Approach

### Model Selection
Several regression models were initially explored and compared:
-   Linear Regression
-   Ridge Regression
-   RandomForestRegressor
-   GradientBoostingRegressor

Initial evaluation using `show_scores` indicated that tree-based models (RandomForestRegressor and GradientBoostingRegressor) performed significantly better than linear models.

### Hyperparameter Tuning
`RandomizedSearchCV` was employed to fine-tune the hyperparameters of both `RandomForestRegressor` and `GradientBoostingRegressor` to optimize their performance. A custom `show_scores` function was used for evaluation, calculating Mean Absolute Error (MAE), Root Mean Squared Log Error (RMSLE), and R-squared (R2) for both training and validation sets. Predictions were clipped at 0 to ensure non-negative rates for RMSLE calculation.

### Best Model
After hyperparameter tuning, the **RandomForestRegressor** model demonstrated slightly better performance on the validation set and was selected as the best model for predictions.

**Tuned RandomForestRegressor Scores:**
-   `Train MAE`: 94.04
-   `Val MAE`: 122.39
-   `Train RMSLE`: 0.1376
-   `Val RMSLE`: 0.1644
-   `Train R2`: 0.8705
-   `Val R2`: 0.8276

## Prediction Workflow

1.  **Load Best Model**: The best-performing `RandomForestRegressor` model was saved using `joblib` as `best_random_forest_model.joblib` and loaded for making predictions.
2.  **Validation Data Prediction**: `validation.csv` was preprocessed using the `preprocess_data` function, ensuring column alignment with the training data. Predictions were then made, and a `validation_predictions.csv` file was generated by merging the `predicted_rate` with the `validation-predictions-template.csv` based on `load_id`.
3.  **December Data Prediction**: `december_chart_inputs.csv` was similarly preprocessed and predictions were made. The `predicted_rate` column in this dataset was updated with the model's output, and the result was saved as `december_chart_inputs_with_predictions.csv`.
